## Language Configuration

### Voice Model Training

Specify the language when training a voice model from audio:

```javascript
/**
 * Train voice model with language specification
 * @param {string} path - Path to audio file
 * @param {string} lang - Language code (zh, en, ja, ko, fr, de, ar, es)
 * @returns {Promise<number|boolean>} Voice model ID or false on failure
 */
export async function train(path, lang = 'zh') {
  path = path.replace(/\\/g, '/') // Normalize path
  
  const res = await preprocessAndTran({
    format: path.split('.').pop(),
    reference_audio: path,
    lang  // Language specification
  })
  
  if (res.code !== 0) {
    return false
  }
  
  const { asr_format_audio_url, reference_audio_text } = res
  return insert({ 
    origin_audio_path: path, 
    lang,  // Store language with model
    asr_format_audio_url, 
    reference_audio_text 
  })
}
```

<Note>
The language parameter affects ASR (Automatic Speech Recognition) accuracy and voice synthesis quality. Always specify the correct language for best results.
</Note>

### API Request Format

**Endpoint**: `http://127.0.0.1:18180/v1/preprocess_and_tran`

**Method**: POST

```json
{
  "format": "wav",
  "reference_audio": "origin_audio/sample.wav",
  "lang": "zh"
}
```

**Example for Different Languages**:

```javascript
// English voice model
await train('audio/english_sample.wav', 'en')

// Japanese voice model
await train('audio/japanese_sample.wav', 'ja')

// Spanish voice model
await train('audio/spanish_sample.wav', 'es')

// French voice model
await train('audio/french_sample.wav', 'fr')
```

## Language-Specific Features

### Automatic Speech Recognition (ASR)

The ASR system automatically transcribes audio in the specified language:

<Steps>
  <Step title="Audio Analysis">
    The system analyzes audio characteristics specific to the chosen language
  </Step>
  
  <Step title="Transcription">
    Speech is converted to text using language-specific models
    
    ```javascript
    const res = await preprocessAndTran({
      format: 'wav',
      reference_audio: audioPath,
      lang: 'ko'  // Korean transcription
    })
    // Returns reference_audio_text with Korean text
    ```
  </Step>
  
  <Step title="Reference Generation">
    Transcribed text becomes the reference for voice synthesis
  </Step>
</Steps>

### Text-to-Speech Synthesis

The TTS engine uses language-aware models for natural speech generation:

```javascript
// Synthesize speech in the model's trained language
const voice = selectVoiceByID(voiceId)
// voice.lang contains the language code

const audioPath = await makeAudio4Video({
  voiceId: voice.id,
  text: "Your content in the voice's language"
})
```

<Tip>
For best results, ensure the text content matches the language of the voice model. Cross-language synthesis may produce unexpected results.
</Tip>

## Multi-Language Workflows

### Creating Content in Multiple Languages

<Steps>
  <Step title="Train Language-Specific Models">
    Create separate voice models for each language you need.
    
    ```javascript
    // Train English voice
    const englishVoiceId = await train('audio/en_sample.wav', 'en')
    
    // Train Japanese voice
    const japaneseVoiceId = await train('audio/ja_sample.wav', 'ja')
    
    // Train Spanish voice
    const spanishVoiceId = await train('audio/es_sample.wav', 'es')
    ```
  </Step>
  
  <Step title="Generate Localized Content">
    Use appropriate voice models for each language version.
    
    ```javascript
    // English video
    await saveVideo({
      model_id: avatarId,
      name: 'Welcome Video - English',
      text_content: 'Welcome to our platform',
      voice_id: englishVoiceId
    })
    
    // Japanese video
    await saveVideo({
      model_id: avatarId,
      name: 'Welcome Video - Japanese',
      text_content: 'プラットフォームへようこそ',
      voice_id: japaneseVoiceId
    })
    ```
  </Step>
  
  <Step title="Synthesize Videos">
    Generate videos for each language version using the same avatar model.
  </Step>
</Steps>

### Language-Specific Avatar Models

You can create avatar models trained with language-specific source material:

```javascript
// Add English-speaking avatar
const englishAvatarId = await addModel(
  'English Avatar',
  'video/english_speaker.mp4'
)
// This will train with lang='zh' by default in the code

// Add Japanese-speaking avatar
const japaneseAvatarId = await addModel(
  'Japanese Avatar', 
  'video/japanese_speaker.mp4'
)
```

<Note>
In the current implementation, `addModel` defaults to Chinese (`zh`) for voice training. For production use, you may want to modify the code to accept a language parameter.
</Note>

## Language-Specific Considerations

### Tonal Languages (Chinese, Vietnamese)

- Ensure training audio has clear tonal distinctions
- ASR accuracy depends on proper tone recognition
- Use native speakers for optimal voice cloning

### Character-Based Languages (Japanese, Korean, Chinese)

- UTF-8 encoding is essential for text input
- Verify character rendering in transcriptions
- Test synthesis with various character combinations

### RTL Languages (Arabic)

- Text direction is handled automatically by the TTS engine
- Ensure source text is properly formatted
- Verify Arabic-specific phonetic features

### Accented Languages (English, Spanish, French)

- Different regional accents can be captured in training
- Select training audio that matches target accent
- Consider creating separate models for different accents

## Technical Implementation

### ASR Integration

The Fun-ASR service handles language-specific speech recognition:

```javascript

export async function train(path, lang = 'zh') {
```

## Localization Workflow Example

Complete example for creating multi-language content:

```javascript
// 1. Train voices for each language
const voices = {
  en: await train('audio/english.wav', 'en'),
  ja: await train('audio/japanese.wav', 'ja'),
  es: await train('audio/spanish.wav', 'es')
}

// 2. Prepare localized content
const content = {
  en: 'Welcome to our service',
  ja: 'サービスへようこそ',
  es: 'Bienvenido a nuestro servicio'
}

// 3. Create videos for each language
for (const [lang, voiceId] of Object.entries(voices)) {
  const videoId = await saveVideo({
    model_id: avatarId,
    name: `Welcome - ${lang.toUpperCase()}`,
    text_content: content[lang],
    voice_id: voiceId
  })
  
  await makeVideo(videoId)
  console.log(`${lang.toUpperCase()} video queued:`, videoId)
}
```

## Troubleshooting

### Poor ASR Accuracy

- Verify correct language code is specified
- Check audio quality and background noise
- Ensure audio contains clear speech in target language

### Unnatural Synthesis

- Confirm text language matches voice model language
- Check for special characters or formatting issues
- Test with simpler text first

### Mixed Language Content

- Create separate videos for each language
- Avoid mixing languages in single text input
- Use language-specific models for each segment
