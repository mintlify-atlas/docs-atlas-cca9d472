## Before Requesting Support

To get the fastest resolution, please complete these steps first:

<Steps>
  <Step title="Check the FAQ">
    Visit our [FAQ page](/community/faq) for answers to common questions and troubleshooting steps.
  </Step>

  <Step title="Verify System Requirements">
    Ensure your system meets the requirements:
    - NVIDIA graphics card with drivers installed
    - Docker services running
    - Sufficient disk space (100GB+ on C:, 30GB+ on D: for Windows)

    ```bash
    # Verify GPU
    nvidia-smi
    ```
  </Step>

  <Step title="Update to Latest Version">
    Make sure you're using the latest version:

    **Server:**
    ```bash
    cd /deploy
    docker-compose up -d
    ```

    **Client:** Download from [GitHub Releases](https://github.com/duixcom/Duix.Avatar/releases)
  </Step>

  <Step title="Search Existing Issues">
    Check if your issue is already reported or resolved in [GitHub Issues](https://github.com/duixcom/Duix.Avatar/issues).
  </Step>
</Steps>

## Reporting Issues

When requesting support, provide detailed information:

### Required Information

<AccordionGroup>
  <Accordion title="Problem Description">
    Clearly describe:
    - What you were trying to do
    - What you expected to happen
    - What actually happened
    - Steps to reproduce the issue
    - Screenshots (if applicable)
  </Accordion>

  <Accordion title="System Information">
    Include:
    - Operating System (e.g., Windows 10, Ubuntu 22.04)
    - GPU Model (e.g., RTX 4070)
    - Client Version
    - Docker service status
  </Accordion>

## Support Options: Open Source vs Commercial

<Note>
  We offer two parallel service solutions to meet different user needs.
</Note>

### Comparison Table

| Aspect | Open Source Local Deployment | Commercial API Service |
|--------|------------------------------|------------------------|
| **Best For** | Technical users with deep learning experience | Business users needing quick integration |
| **Hardware** | Requires GPU server purchase | No GPU required |
| **Customization** | Full source code access and modification | API-based extension only |
| **Support** | Community support | Professional technical response team |
| **Maintenance** | High maintenance cost | Simple maintenance |
| **Lip Sync** | Usable effect | Stunning, higher definition |
| **Updates** | Community-driven | Latest models prioritized, fast fixes |
| **License** | Free commercial use* | Commercial use allowed |

<Note>
  *Enterprises with 100,000+ users or $10M+ annual revenue need a commercial license
</Note>

### When to Choose Open Source

<Card title="Open Source Deployment" icon="code-branch">
  Choose the open-source version if you:
  
  - Have deep learning framework experience
  - Need full customization and control
  - Want to participate in community development
  - Can maintain your own infrastructure
  - Have budget for GPU hardware
</Card>

### When to Choose Commercial API

<Card title="Commercial API Service" icon="rocket">
  Choose the commercial API if you:
  
  - Need quick business integration
  - Want to focus on application development
  - Require enterprise-level SLA guarantees
  - Prefer managed infrastructure
  - Need the latest models and fastest updates
</Card>

## Supported Platforms

### Operating Systems

- **Windows**: Windows 10 19042.1526 or higher
- **Linux**: Ubuntu 22.04 (tested), other distributions may work

### Hardware Requirements

**Minimum:**
- NVIDIA GPU (RTX 4070 or better recommended)
- 32GB RAM
- 100GB+ free disk space

**Recommended:**
- CPU: 13th Gen Intel Core i5-13400F
- Memory: 32GB
- GPU: RTX 4070 or RTX 5090

### GPU Support

<AccordionGroup>
  <Accordion title="Supported GPUs">
    NVIDIA GPUs with proper drivers:
    - RTX 50 Series (tested on 5090)
    - RTX 40 Series (4070 recommended)
    - RTX 30 Series

    Download drivers: [nvidia.cn/drivers/lookup](https://www.nvidia.cn/drivers/lookup/)
  </Accordion>

  <Accordion title="GPU Verification">
    Verify your GPU is detected:
    ```bash
    nvidia-smi
    ```

    This command should display your GPU model, driver version, and CUDA version.
  </Accordion>
</AccordionGroup>
