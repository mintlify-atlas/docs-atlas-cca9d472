By contributing to Duix Avatar, you're helping democratize digital human creation technology.

## Before You Contribute

### Self-Check Guidelines

Before opening an issue or pull request:

<AccordionGroup>
  <Accordion title="1. Search Existing Issues">
    Check if your issue or feature request already exists in [GitHub Issues](https://github.com/duixcom/Duix.Avatar/issues).

    The community is very active, and your concern might already be addressed or in progress.
  </Accordion>

  <Accordion title="2. Use the Latest Version">
    Ensure you're using the latest version of both server and client:

    **Update Server:**
    ```bash
    cd /deploy
    docker-compose up -d
    ```

    **Update Client:**
    Download from [GitHub Releases](https://github.com/duixcom/Duix.Avatar/releases)
  </Accordion>

  <Accordion title="3. Test Your Environment">
    Verify your environment meets the requirements:

    - NVIDIA graphics card with proper drivers installed
    - All three Docker services running
    - Sufficient disk space (100GB+ on C:, 30GB+ on D: for Windows)

    ```bash
    # Verify GPU drivers
    nvidia-smi
    ```
  </Accordion>
</AccordionGroup>

## Reporting Issues

When reporting a bug, please use this template:

### Issue Template

```markdown
## Problem Description

[Describe the issue in detail]

### Steps to Reproduce

1. [First step]
2. [Second step]
3. [And so on...]

### Expected Behavior

[What you expected to happen]

### Actual Behavior

[What actually happened]

### Screenshots

[If applicable, add screenshots]

## Environment

- **OS**: [e.g., Windows 10, Ubuntu 22.04]
- **GPU**: [e.g., RTX 4070]
- **Client Version**: [e.g., v1.0.0]
- **Docker Services**: [Running/Not Running]

## Error Logs

### Client Logs

[Paste client logs here]

### Server Logs

[Paste Docker service logs here]
```

<Note>
  **Getting Logs:**
  - **Client Logs**: Available in the application settings
  - **Server Logs**: Click on Docker services in Docker Desktop and copy logs
</Note>

## Contributing Code

### Development Setup

<Steps>
  <Step title="Fork the Repository">
    Fork the [Duix Avatar repository](https://github.com/duixcom/Duix.Avatar) to your GitHub account.
  </Step>

  <Step title="Clone Your Fork">
    ```bash
    git clone https://github.com/YOUR_USERNAME/Duix.Avatar.git
    cd Duix.Avatar
    ```
  </Step>

  <Step title="Install Dependencies">
    Ensure you have Node.js 18 installed:
    ```bash
    node --version  # Should be v18.x
    npm install
    ```
  </Step>

  <Step title="Set Up Docker Services">
    Pull the required Docker images:
    ```bash
    docker pull guiji2025/fun-asr
    docker pull guiji2025/fish-speech-ziming
    docker pull guiji2025/duix.avatar
    ```

    Start services:
    ```bash
    cd deploy
    docker-compose up -d
    ```
  </Step>

  <Step title="Create a Branch">
    ```bash
    git checkout -b feature/your-feature-name
    ```
  </Step>
</Steps>

### Code Style

- Follow existing code patterns and conventions
- Write clear, descriptive commit messages
- Add comments for complex logic
- Test your changes thoroughly before submitting

### API Integration

When working with APIs, refer to these core service files:

```bash
src/main/service/model.js   # Model training API
src/main/service/video.js   # Video synthesis API
src/main/service/voice.js   # Voice cloning API
```

### Submitting Pull Requests

<Steps>
  <Step title="Commit Your Changes">
    ```bash
    git add .
    git commit -m "feat: add amazing new feature"
    ```

    Use conventional commit messages:
    - `feat:` for new features
    - `fix:` for bug fixes
    - `docs:` for documentation
    - `refactor:` for code refactoring
  </Step>

  <Step title="Push to Your Fork">
    ```bash
    git push origin feature/your-feature-name
    ```
  </Step>

  <Step title="Create Pull Request">
    1. Go to the original repository
    2. Click "New Pull Request"
    3. Select your fork and branch
    4. Fill in the PR template with details
    5. Submit the pull request
  </Step>
</Steps>
