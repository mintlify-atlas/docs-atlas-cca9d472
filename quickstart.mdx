## Welcome to Duix Avatar

Duix Avatar is a fully offline video synthesis tool that can precisely clone your appearance and voice, allowing you to create videos by driving virtual avatars through text and voice. This guide will help you generate your first AI avatar video.

<Note>
  Duix Avatar runs completely offline, protecting your privacy while providing efficient digital human creation capabilities.
</Note>

## Your First Avatar Video

Once you have both the server and client installed, follow these steps to create your first AI avatar video:

<Steps>
  <Step title="Verify Docker Services">
    Open Docker Desktop and ensure all three services are running:
    - `duix-avatar-tts` (Text-to-Speech service on port 18180)
    - `duix-avatar-asr` (Speech Recognition service on port 10095)
    - `duix-avatar-gen-video` (Video Generation service on port 8383)
    
    All services should show "Running" status.
  </Step>

  <Step title="Launch the Client">
    <CodeGroup>
    ```bash Windows
    # Double-click the installed application
    # Or launch from Start Menu: Duix.Avatar
    ```
    
    ```bash Ubuntu
    # Double-click the AppImage file or run:
    ./Duix.Avatar-x.x.x.AppImage
    
    # If logged in as root, use:
    ./Duix.Avatar-x.x.x.AppImage --no-sandbox
    ```
    </CodeGroup>
  </Step>

  <Step title="Create Your Avatar Model">
    Before generating videos, you'll need to train your avatar model:
    
    1. **Prepare Training Data**
       - Record a video of yourself speaking (2-5 minutes recommended)
       - Ensure good lighting and clear audio
       - Face the camera directly
    
    2. **Train the Model**
       - In the client, navigate to the "Model Training" section
       - Upload your video
       - The system will automatically separate video and audio
       - Wait for the training process to complete (typically 10-30 minutes)
    
    <Note>
      The training quality directly impacts your avatar's realism. Use high-quality video with clear speech for best results.
    </Note>
  </Step>

  <Step title="Generate Your First Video">
    With your trained model ready:
    
    1. Select your trained avatar model
    2. Input your text script or upload an audio file
    3. Choose your preferred settings:
       - Language (supports 8 languages: English, Japanese, Korean, Chinese, French, German, Arabic, Spanish)
       - Video quality settings
    4. Click "Generate Video"
    5. Wait for the synthesis to complete
    
    The video generation process typically takes a few minutes depending on length and complexity.
  </Step>

  <Step title="Review and Export">
    Once generation is complete:
    - Preview your AI avatar video
    - Make adjustments if needed
    - Export in your desired format
    - Share or use in your projects
  </Step>
</Steps>

## API Integration

For developers looking to integrate Duix Avatar into their applications, the system exposes local APIs:

```javascript
// Model Training API
POST http://127.0.0.1:18180/v1/train

// Audio Synthesis API
POST http://127.0.0.1:18180/v1/invoke

// Video Synthesis API
POST http://127.0.0.1:8383/easy/submit

// Progress Query
GET http://127.0.0.1:8383/easy/query?code={taskCode}
```

<Note>
  For detailed API documentation, refer to the source code in `src/main/service/` directory:
  - `model.js` - Model training endpoints
  - `video.js` - Video synthesis endpoints
  - `voice.js` - Voice cloning endpoints
</Note>

## Troubleshooting

If you encounter issues:

1. **Services Not Starting**
   - Verify NVIDIA drivers are installed: Run `nvidia-smi` in terminal
   - Check Docker has GPU access enabled
   - Ensure sufficient disk space (100GB+ required)

2. **Video Generation Fails**
   - Confirm all three Docker services are running
   - Check Docker logs for specific error messages
   - Verify model training completed successfully

3. **Client Won't Launch**
   - Update to the latest version from [GitHub Releases](https://github.com/duixcom/Duix.Avatar/releases)
   - On Ubuntu, try running with `--no-sandbox` flag if you're root user
   - Check client logs (accessible from the application menu)

<Warning>
  Always ensure you're running the latest versions of both server (Docker images) and client. The project is actively developed with frequent updates.
</Warning>
